# Software Engineer Intern — Northwind Labs, Bengaluru

Northwind Labs builds internal tools for factory teams. We are hiring a software engineer intern for 6 months, starting this summer, onsite in Bengaluru.

## What you will do

- Ship small features on a Python API used by the factory dashboard.
- Pair with a senior engineer on React pages for that dashboard.
- Write SQL queries against PostgreSQL and explain what they do in review.

## What we expect

- A bachelor's degree in progress in computer science or a related field.
- One project you can demo that used Python on the backend.
- Comfort reading JavaScript. React is a plus, not a requirement.
- This internship does not require prior full-time work experience.

## Terms

- Stipend: ₹35,000 per month.
- Onsite, five days a week, Bengaluru. Relocation support is a one-time travel reimbursement.
- No service bond. The offer letter does not ask you to repay training fees if you leave.

## How to apply

Send a resume and a short note about one project you built. We read the note before the resume.
